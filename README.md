# mypage

プロフィールページ（GitHub Pages で公開）。スマートフォン閲覧を前提に作ってある。

## ファイル

| ファイル | 役割 |
|---|---|
| `index.html` | 公開ページ本体。単体で完結（外部依存なし） |
| `profilepig.jpeg` | プロフィール写真 |
| `pin-tool.html` | PIN 暗号文の生成ツール。**公開しない**（`.gitignore` で除外） |

## 編集する場所

`index.html` 下部の `<script>` 内、**「▼▼▼ 編集はこのブロックだけ ▼▼▼」から「▲▲▲」までの間**だけを触る。
その下は描画処理なので、通常はさわらなくてよい。

### 1. PROFILE — 名前・所属

```js
const PROFILE = {
  name:   "池田 悠耶",
  romaji: "Yuya Ikeda",
  photo:  "profilepig.jpeg",
  meta: [                                    // 見出し下に並ぶ基本情報。行は自由に増減できる
    { label: "所属", value: "○○大学大学院 △△研究科 博士前期課程" },
    { label: "専攻", value: "△△専攻 ○○研究室" },
  ],
};
```

### 2. SECTIONS — 中身

配列の順番がそのままページの並び順とナビの並び順になる。
`nav` がナビに出る短い名前、`title` が見出し。`type` で表示形式が決まる。

| `type` | 表示 | 主なキー |
|---|---|---|
| `about` | 文章（`stats` を書けば件数も出る） | `body`（段落の配列）, `stats` |
| `research` | 研究キーワード（`fields` に書けば補足も出る） | `keywords`, `fields` |
| `career` | 期間つきのリスト | `items`（`period` / `title` / `org` / `note`） |
| `works` | 業績リスト（種類ごと） | `groups`（`label` / `items`） |
| `links` | リンクボタン | （`LINKS` を参照するので追加設定なし） |

補足:

- `about` の `stats` は既定で空（件数を出さない）。出したいときは `stats: [{ label: "論文", value: "auto:論文" }]` のように書くと、業績セクションの件数を自動で数える。
- 業績のグループは `items: []` にしておくと「なし」と表示される（受賞欄など）。文言は `none: "該当なし"` で変えられる。
- 業績は 1 グループ 4 件まで表示し、5 件目以降は「すべて表示」ボタンでひらく。
- 業績の `url` を空文字にすると、リンクなしの行として表示される。

セクションごと不要なら、`SECTIONS` からそのブロックを削除すればナビからも消える。

### 3. LINKS — リンクボタン

```js
{
  title: "LinkedIn",
  sub:   "経歴・つながり",          // 小さい説明（省略可）
  url:   "https://example.com",
  icon:  "linkedin",               // linkedin / line / mail / x / github / note / researchmap / link
  color: "#0A66C2",
},
```

## PIN で保護されたリンク

`url` の代わりに `enc`（AES-256-GCM の暗号文）と `pin`（桁数）を持たせると、
PIN を入力しないと開けないリンクになる。URL はソースに平文で残らない。

入力画面の案内文は既定で「名刺の右下に記載されている 4 桁を入力してください」。
リンクに `desc: "…"` を書けば、そのリンクだけ文言を変えられる。

PIN や URL を変更する手順:

1. `pin-tool.html` をブラウザで開く
2. URL と PIN を入力して「暗号文を作る」
3. 出力された文字列を `index.html` の `enc: "..."` に貼り替える

復号には `crypto.subtle` が必要なので、**https（GitHub Pages）で開くこと**。
`file://` で開くと PIN リンクだけ動かない。

## スマホ対応で入れてあること

- セーフエリア（ノッチ・ホームバー）を `env(safe-area-inset-*)` で回避
- 上部のナビは横スクロール式・スクロールに追従し、現在のセクションを自動でハイライト
- タップ領域は最低 44px、タップ時のハイライトは無効化
- PIN 入力は数字キーパッド（`inputmode="numeric"`）、複数桁がまとめて入力されても各桁に分配
- 「共有」ボタンは OS の共有シート（`navigator.share`）を使い、非対応ならリンクをコピー

## 見た目の方針

白地・罫線・文字だけで構成する。影・カード・ぼかし・グラデーション・スクロールアニメーションは使わない。
色はリンク色（`--accent`）と各サービスのアイコン色だけに限定する。
